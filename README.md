## Research interests

I’d like to study **trustworthy AI** in graduate school. Two questions I keep coming back to: **What did the model rely on? What changes after fine-tuning?** I’m interested in using interpretability and language model evaluation to understand where models fail and when people should review their outputs.

## 한국어

상명대학교 휴먼AI공학전공 학부생 이선역입니다. 대학원에서는 **신뢰할 수 있는 AI**를 연구하고 싶습니다. 모델이 어떤 근거로 답을 내는지, 파인튜닝을 거치면 어떤 오류가 줄고 어떤 오류가 남는지에 관심이 있습니다. 모델의 판단을 설명하고 평가하는 방법을 공부하며, 사람이 언제 개입해야 하는지도 살펴보고 싶습니다.

TRAITHON에서는 탐지 결과의 근거와 사람의 검토 절차를 설계했고, 문서 AI 비서에서는 답변에 사용한 문서 구절을 보여주는 화면을 만들었습니다. 태양풍 예측 프로젝트에서는 팀을 이끌고 앙상블 실험에 참여해 대회에서 **팀 2위**를 했습니다. GDGoC SMU에서는 LLM 실습 스터디를 운영합니다.
