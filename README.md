## Research interests

I hope to pursue graduate research in **trustworthy and explainable AI**. I'm interested in what a model relies on when it gives an answer, how that changes after fine-tuning, and when a user should double-check the result. I want to study these questions through model evaluation, with a longer-term interest in AI safety and value alignment.
