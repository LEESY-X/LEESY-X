## Research interests · 연구 관심사

I hope to pursue graduate research in **trustworthy and explainable AI**. I'm interested in how fine-tuning changes model behavior, how we can check the evidence behind an answer, and when a person should step in. I'd like to study these questions through model evaluation, with a longer-term interest in AI safety and value alignment.

상명대학교 휴먼AI공학전공 학부생 이선역입니다. 대학원에서는 **신뢰할 수 있고 설명 가능한 AI**를 연구하고 싶습니다. 파인튜닝이 모델의 판단을 어떻게 바꾸는지, 답변의 근거를 어떻게 검증할지, 어떤 상황에서 사람이 개입해야 하는지에 관심이 있습니다. 모델 평가를 바탕으로 AI 안전성과 가치 정렬까지 탐구하고 싶습니다.
