## Research interests

I’m interested in **trustworthy AI**, especially model interpretability and language model evaluation. In graduate school, I’d like to study whether explanations reflect what a model actually used to make a decision, and which errors fine-tuning fixes or leaves behind. I’m also interested in how that evidence can help people decide when to step in.
